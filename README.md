# 🎮 ПУТЬ — Игра-загадка с элементами ARG

Добро пожаловать в **ПУТЬ** — интерактивную игру-головоломку на 100 уровней, разработанную на чистом JavaScript, HTML и CSS. 

## 📝 Описание проекта
Это не просто набор логических задач. Игра включает в себя:
*   **100 уникальных уровней** (логика, математика, реакция, память).
*   **Скрытые пасхалки** и элементы Alternate Reality Game (ARG).
*   **Секретные режимы**: Уровень Цезаря (исторический квиз) и Уровень -666 (мистический хардкор).
*   **Процедурный звук**: Звуковые эффекты генерируются на лету с помощью Web Audio API (без тяжелых MP3-файлов).
*   **Система сохранений**: Прогресс и найденные секреты сохраняются в `localStorage`.

## 🛠 Технологии
*   **HTML5 / CSS3** (Адаптивный дизайн, кастомные анимации).
*   **Vanilla JavaScript (ES6+)** (Без сторонних библиотек и фреймворков).
*   **Web Audio API** (Синтез звука).
*   **LocalStorage API** (Сохранение прогресса).

## 🚀 Как запустить
Просто откройте файл `index.html` в любом современном браузере. Игра не требует сервера или установки зависимостей.

Или перейдите по ссылке (если настроен GitHub Pages):
